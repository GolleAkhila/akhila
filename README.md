# Student Record Management System

## Description

A beginner-friendly Python project for managing student records using CRUD operations.

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Exit

## Technologies Used

- Python
- CSV

## Concepts Used

- Python Functions
- Lambda Functions
- List Comprehensions
- File Handling
- CSV
- Exception Handling
- Loops
- Conditional Statements

## CRUD Operations

- Create - Add Student
- Read - View Students
- Update - Update Student
- Delete - Delete Student
